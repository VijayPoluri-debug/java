## Key Learning

This week focused on understanding how strings are handled in Java and how object-oriented programming is used to organize data and behavior inside classes.

I practiced creating classes, objects, methods, constructors, and private fields. I also used getter and setter methods to understand basic encapsulation.

The mini Student Management application combined classes, objects, methods, and user input into one simple console program.
